# Contributing

MJDF's public GitHub repository is **binary-only**. Application source code is not published here, so normal source-code pull requests are not part of the public contribution workflow.

## Useful contributions

Public contributions are still valuable in the following forms:

- reproducible bug reports;
- compatibility reports for specific Windows builds;
- DNS/WFP behavior observations;
- Rules persistence and rule-semantics regression reports;
- dashboard usability reports;
- documentation corrections;
- feature requests with a concrete use case.

Use the repository Issues forms where possible. Include the MJDF release version, Windows version, route state (Attached/direct), relevant logs with private data removed, and exact reproduction steps.

## Security issues

Do not publish a working filtering bypass, privilege issue, certificate/key issue, or other exploitable security defect in a public Issue. Follow [`SECURITY.md`](SECURITY.md).

## Documentation changes

If public documentation contributions are enabled later, documentation-only pull requests may be accepted at the maintainer's discretion. Publication of documentation does not imply publication or licensing of the application source code.
