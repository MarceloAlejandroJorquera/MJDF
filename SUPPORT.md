# Support

Use GitHub Issues for reproducible bugs and GitHub Discussions (if enabled) for configuration/how-to questions.

Before filing a bug:

1. confirm the latest public v1 binary is being tested;
2. note whether the tray and dashboard show the same route state;
3. record whether Windows DNS is local (`127.0.0.1` / `::1`) or direct;
4. reproduce with and without browser-specific encrypted-DNS behavior when relevant;
5. review `%LOCALAPPDATA%\MJDF\logs`;
6. sanitize domain history and Rules before attaching diagnostics.

For security-sensitive reports, use `SECURITY.md` instead of a normal public Issue.
