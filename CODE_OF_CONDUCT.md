# Code of Conduct

Participation in the MJ DNS FILTER repository should remain technical, respectful and focused on improving the software.

## Expected behavior

- Discuss code, evidence and reproducible behavior rather than attacking contributors.
- Assume good faith while still reviewing security-critical claims rigorously.
- Respect privacy; do not pressure users to publish sensitive DNS history or machine data.
- Give credit for substantial technical contributions.
- Keep issue discussions on topic.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, doxxing, deliberate disclosure of private user data, spam, or knowingly misleading security claims are not acceptable.

Maintainers may edit, hide or remove content and may restrict participation when necessary to keep the project usable and safe.

Security vulnerabilities should follow `SECURITY.md` rather than being used to publicly expose users before a fix is available.
